# Focus Guard v5

- GitHub Pages용 정적 웹앱
- 카메라 영상 업로드/저장 API 없음
- 집중/휴식 자동 전환 및 휴식 중 카메라 OFF
- 경고음 선택 및 미리듣기
- 핑크/블링블링 테마
- 졸음 판정 로직(눈 감음/고개 끄덕임)이 분리되어 있음

주의: 이 v5 파일은 카메라/타이머/개인정보 보호 구조를 완성했지만,
현재 배포 파일에는 실제 얼굴 랜드마크 엔진을 외부 CDN에서 불러오지 않습니다.
따라서 '눈 5분/반복 끄덕임'의 실제 얼굴 인식은 아직 활성화되지 않은 상태입니다.
학교 네트워크나 CDN 문제를 피하려면 얼굴 인식 엔진과 모델을 로컬 파일로 번들하는 것이 다음 단계입니다.
